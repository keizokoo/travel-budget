지출 추가

해외통화 선택 시 그날 실제 적용된 환율을 입력해주세요. 마지막 입력값을 기억해둡니다.

일자별 요약

📥 구글 타임라인 파일 다운로드 방법
📱 Android
  1. 휴대폰 [설정] 앱 → [위치] (또는 [위치 서비스])
  2. [타임라인] 선택
  3. [타임라인 데이터 내보내기] 탭
  4. [계속] → [저장] — JSON 파일이 휴대폰에 저장됩니다
🍎 iPhone
  1. 구글 지도 앱 실행 → 우측 상단 프로필 아이콘 탭
  2. [내 타임라인] 선택
  3. 우측 상단 점 3개(⋯) 메뉴 → [위치 및 개인정보 설정]
  4. [타임라인 데이터 내보내기] 탭
저장된 파일(보통 Timeline.json)을 "타임라인 업로드" 버튼으로 선택하면 이 화면에 자동 반영됩니다. 일부 EU 지역 계정은 JSON 대신 CSV로 저장될 수 있는데, 이 경우는 아직 지원되지 않습니다.

국가 관리

통화 관리

KRW는 원화 그대로, 그 외 통화는 지출 추가 시 환율을 입력하면 자동으로 원화 환산됩니다.

카드 구분 관리

지출 추가 시 결제수단을 "카드"로 선택하면 여기서 등록한 카드 구분 중 하나를 고를 수 있습니다.

환율 관리

여기서 저장해두면 해당 통화로 지출을 추가하거나 카드승인 문자를 인식할 때 환율이 자동으로 채워집니다.

저장공간 사용량

영수증 사진은 브라우저 저장공간(localStorage)에 압축되어 저장됩니다. 사진이 많아지면 공간이 부족해질 수 있으니, 아래 "내보내기"로 주기적으로 백업해두는 것을 권장합니다.

데이터 백업 / 복원 (파일)

브라우저 저장공간이 초기화되어도 데이터를 잃지 않도록, 주기적으로 내보내기 파일을 보관해두는 것을 권장합니다.

Google Drive 자동 백업

URL은 Apps Script를 웹 앱으로 배포하면 발급됩니다. 영수증 사진을 포함한 전체 데이터가 Google Drive에 JSON 파일로 저장되며, 최근 5개 이력도 함께 보관됩니다.

여행 삭제

현재 선택된 여행과 그 안의 모든 지출 내역이 삭제됩니다. 되돌릴 수 없으니 먼저 내보내기로 백업해두세요.
