📋 엑셀에서 붙여넣기로 일괄 등록

엑셀에서 종목명 · 종목코드 · 수량 · 평균매수가 순서로 4개 열을 선택해 복사(Ctrl+C)한 뒤 아래 칸에 붙여넣어주세요(Ctrl+V). 종목코드가 없으면 3개 열(종목명·수량·평균매수가)만 붙여넣어도 돼요.

☁ 클라우드 동기화 (Google Sheets)

구글시트를 데이터 저장소로 사용해서 여러 기기에서 같은 자산 데이터를 관리할 수 있어요. 아래 설정을 한 번만 완료하면, 이후엔 이 기기에서도 앱을 열 때 자동으로 동기화돼요("저장하기 / 불러오기" 버튼은 지금 바로 반영하고 싶을 때만 누르면 돼요).

✅ Apps Script에 매일 16:10(장 마감 후) 자동 실행 트리거(setupDailyTrigger)를 등록해두면, 앱을 아예 열지 않은 날에도 서버가 종목별 시세를 자동으로 갱신해서 시트에 저장해요. 앱을 열면 그 데이터를 자동으로 받아와요(pull) — 더 이상 "현재가 새로고침"을 매일 직접 누를 필요가 없어요(장중 실시간 시세가 필요할 때만 눌러주세요).

⚠ 복구 전용 — 백업 복원 직후 1회성 확정 저장
위 "클라우드에 저장"은 저장 전에 클라우드를 먼저 불러와 병합하는데, 클라우드가 옛 값을 갖고 있으면 방금 복원한 로컬 값이 다시 훼손됩니다. 복원 직후엔 아래 버튼으로 병합 없이 그대로 덮어써서 확정하세요.

⚠️ 동기화 중에는 이 화면을 벗어나지 마세요 — 다른 앱으로 전환하거나 화면을 끄면 모바일 브라우저가 통신을 일시정지시켜 동기화가 실패할 수 있어요(브라우저 공통 동작). 60초 넘게 응답이 없으면 자동으로 시간 초과 처리돼요.

⚠️ 이 URL을 아는 사람은 누구나 데이터를 읽고 쓸 수 있어요. URL을 다른 사람과 공유하지 마세요.
